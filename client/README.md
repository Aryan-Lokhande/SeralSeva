# 🌐 Yojna Saathi 

A full-stack government service and grievance management platform designed to streamline citizen–government interactions through digital workflows, real-time tracking, and intelligent recommendations.

---

## 🚀 Overview

Yojna Sathi simplifies access to government schemes and enables citizens to apply, track applications, and raise grievances through a unified digital interface. The platform also equips administrators with powerful tools to manage applications, resolve issues, and monitor system activity efficiently.

---

## ✨ Key Features

* **Scheme Discovery & Application**
  Browse, filter, and apply for government schemes with a seamless online process.

* **Real-Time Tracking**
  Track applications and grievances using unique tracking IDs with status updates.

* **Admin Dashboard**
  Manage schemes, applications, users, and grievances through a centralized control panel.

* **Cloud-Based Document Uploads**
  Secure file handling using Cloudinary with scalable storage and CDN delivery.

* **Email Notifications**
  Automated updates for application submission, approval, and rejection using Nodemailer.

* **Smart Scheme Recommendation**
  ML-powered microservice suggests personalized schemes based on user attributes.

---

## 🧠 System Design

The platform follows a modular full-stack architecture with a microservice-based ML integration:

* **Frontend:** React (SPA with dynamic routing and responsive UI)
* **Backend:** Node.js + Express (REST API architecture)
* **Database:** MongoDB (schema-based design with relationships)
* **ML Service:** FastAPI (Python-based recommendation engine)
* **Storage:** Cloudinary (cloud + CDN-based file handling)

---
